# Task 2 — Interactive Dashboard UI

An intermediate-level responsive dashboard built using HTML, CSS, and JavaScript. This project demonstrates modern dashboard design with interactive components, dynamic data handling, and a user-friendly interface.

## Features

* Responsive dashboard layout for desktop, tablet, and mobile devices.
* Statistics cards displaying revenue, orders, customers, and conversion rate.
* Interactive revenue chart with monthly and weekly views.
* Searchable and filterable orders table.
* Add new orders through an interactive form.
* Delete orders dynamically.
* Sidebar navigation with active states.
* Toast notifications for user actions.
* Clean and modern UI with responsive styling.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)

## Project Structure

```text
task2-dashboard/
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Explore the dashboard and interact with its features.

## Learning Outcomes

This project helped me practice responsive web design, JavaScript DOM manipulation, event handling, dynamic data rendering, search and filtering, and basic form validation.
